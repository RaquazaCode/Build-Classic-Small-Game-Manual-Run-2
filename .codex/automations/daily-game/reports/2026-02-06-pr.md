## Title
Automation: Daily classic game MVP (2026-02-06)

## Description
### Concept + Twist
Implemented **Shrinking Snake**: a classic Snake loop with a low-risk original twist where the arena collapses inward every 30 points, creating escalating pressure.

### How To Run and Play
1. `cd games/2026-02-06-shrinking-snake`
2. `npm install`
3. `npm run dev`
4. Open `http://localhost:5173`
5. Controls: Arrows/WASD move, `P` pause, `R` restart, `F` fullscreen.

### What Was Verified
- `npm test -- --run`
- `npm run build`
- Playwright web-game automation run with screenshot/state capture via `web_game_playwright_client.js`.
